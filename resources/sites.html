Related Sites

In addition to our web site, useful information about GNUstep can be found on other sites. We know about these sites.

  • News and info:
    • GNUstep.us - news site run by cbv (with RSS feed)
    • GNUstep.de - Alternative GNUstep info site, also in German
    • GNUstep.net - "Community website"
    • Freshmeat
  • Projects:
    • GNUstep Wiki - random access notes
    • Backbone - GNUstep Desktop project
    • GNUstep Live CD Project - based on Morphix
    • Simply GNUstep - Project to produce a distribution with GNUstep
    • LinuxStep - Project to produce a GNUstep distribution
    • Interface WM - Window Manager in objective C
    • ImageApps - Getting the Picture
    • GNUstepWeb - Web development suite
  • Developer sites:
    • GNUstep.it - developer site
    • Advogato - basic GNUstep project info and links to some developer diaries
    • Project Page - Developer area on Savannah
    • Collaboration World - home to GNUMail, Affiche and more
    • GNUstep HelpCenter
    • GNUstep Corner - fabien's files
    • GNUstep Icons project

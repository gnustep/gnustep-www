The Adaptor Level

The Adaptor Level is the lowest level in GDL and only it deals with the details of accessing each specific database server. The Database Level which is above it uses its methods to perform all of its database operations.

The Adaptor Level is composed from four classes:

EOAdaptor
It represents a database from the database server and it keeps the model and the connection dictionary. All the server specific formatting of SQL expressions is performed here. An adaptor instance keeps a list of adaptor contexts which are used to represent several database transaction scopes on the database.
EOAdaptorContext
Instances of this class represent a unique transaction scope within database server. However if the database server allows nested transactions other transactions can be nested inside the original one. An adaptor context has a list of adaptor channels that represent distinct operation channels within the same transaction. Concrete adaptors may not support more than one channel per context.
EOAdaptorChannel
This is the class that actually keeps a connection with the database server. It executes all the select, insert, update and delete operations within database. The EOAdaptorChannel maps the records from the database into dictionary rows that are further passed to the Database Level.
EOSQLExpression
This class is used to generate the SQL operations. It knows how to generate the four basic SQL operations: select, insert, update and delete. You normally do not use directly this class, it is used internally by the adaptor classes.

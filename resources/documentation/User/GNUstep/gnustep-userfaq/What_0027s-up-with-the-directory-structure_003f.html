1.3.4 What’s up with the directory structure? ¶

First of all, GNUstep uses a slightly different directory structure than NEXTSTEP or Mac OS X. Part of this is historical, part is because we can’t do things the same way (see see Why not use framework bundles?). Although currently the structure is very similar to the one used in Mac OS X.

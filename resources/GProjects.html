Projects using GNU's Objective-C

A list of projects built upon GNU Objective-C.
  • AgentD - A modular scheduling daemon. Including a nice feature about the advantages of ObjC over C and C++.
  • MathArray is a general library of classes for performing mathematical operations on arrays (vectors, matrices, etc) of values. By Adam Fedor. MathArray-1.0 is available from the the GNUstep FTP contrib site
  • The Computer Algebra Kit is a collection of small programs, or "objects", for computer algebra.
  • The Swarm Simulation System is a software package for multi-agent simulation of complex systems. Includes a nice list of links regarding Objective-C.

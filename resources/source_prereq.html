GNUstep: Prereq

Source

Sources Version Notes
gcc >=2.8.0 (Required) GNU Objective-C Compiler
ffcall 1.8d (Highly Recommended) message forwarding
libobjc 1.2.0 (Recommended for gcc < 3.0) unreleased bug fixes
libxml >=2.x For XML property lists and docs
openssl any For https with NSURL, NSURLHandle
iconv any Unless you have glibc >= 2.1
tiff >=3.4beta36 For images

RPMs are available in the rpm directory on the ftp servers. Look for the source and other packages on the main ftp site or mirrors

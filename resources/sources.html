External packages and libraries

This is a list of packages and libraries that are not part of GNUstep, but are required or recommended for using GNUstep. In many cases some of these packages may already be installed on your computer (particularly GNU/Linux and BSD distributions), so check first before you download them.

The GNUstep LaunchPad

The GNUstep LaunchPad is a collection of packages that allow one to write non-graphic tools and applications. These include the Makefile Package, Foundation classes, and bindings to other languages such as Java and guile.

The GNUstep Core

The GNUstep Core pacakge contains all the libraries needed to develope graphical applications based on the OpenStep and MacOS X interfaces. These include implementations of the Foundation and AppKit libraries. Make sure you get whatever prerequisite external packages before you install Core (see above).

Some of these packages are shared with the GNUstep LaunchPad.

Source/CVS Access

GNUstep has a Project Page where you can get source information, access to the CVS source via the web and Anonymous CVS access.

Current snapshots are available at

  • ftp://ftp.gnustep.org/pub/daily-snapshots/

Beware that some users have experienced problems with corrupt files download from ftp.gnustep.org. This may be due to a problem with your particular route to the machine. If you have this problem try using a mirror site or download using the http interface.

FreeBSD Users

FreeBSD users can use the ports directory to install GNUstep: 
cd /usr/ports/devel/gnustep; make; make install
as root

Debian Users

There are also debian packages available. I assume they are in some normal debian location. Ask if you can't find them.

Display Ghostscript System (dgs)

The Display Ghostscript System is needed on operating systems which do not have the Adobe Display PostScript System. Most commercial UNIX systems by Sun, HP, IBM, Digital come with Adobe's DPS as part of the X Window System. The Linux/GNU operating system, however, is one major exception, so the GNUstep developers have decide to create their own implementation that is royalty-free and freely distributable.

Call for Developers

The GNU project is soliciting volunteers to work on Display Ghostscript, an extension to the ghostscript program which will work as a Display PostScript (DPS) server.

L. Peter Deutsch of Aladdin has done much of the work necessary to extend Ghostscript so that it can handle the DPS extensions. There remains more things to be done.

  • Test the current release on many systems
  • Need better context switching code
  • Work on updates using code from the expected GNU dgs6.0 release.
  • Improve speed (via either shared memory or threading?)
  • Many other things...

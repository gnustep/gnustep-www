GNUstep Task List

Following is a list of tasks that need to be completed for upcoming planned releases. An overview of each task is given along with a specific list of tasks that need to be done. ALL of these tasks are open for some one to take on (unless the task is in italics). To start a task, please talk to the persion in charge of that section (listed in the Who's Who) or contact the GNUstep Maintainers. If you are already working on something here, please let us know! To add something, contact the the GNUstep maintainers.

If the high priority tasks look too much for you, or if you want to add a small lower poiority task, please look at the bug/task tracking database

GNUstep Developer Tools

Apart from its great API and libraries GNUstep features some world class developer tools. As these tools aid you in the daily aspects of programming and project management you will notice how much quicker and easier developing is with GNUstep.
With these tools GNUstep extends its sense of rapid application developement even one more step...

GUI Tools

GNUstep features two great graphical applications that help you to manage and create new projects, design and edit graphical user interfaces, compile and debug your programs.

Project Center

Project Center is GNUstep's graphical integrated developement environment (IDE). It helps you to create all different kinds of projects like Applications, Tools, Libraries and Bundles.

Project Center allows you to easily add and remove, edit and search files; writes the project makefiles accordingly and supports you in the actual process of building and debugging your project.

Even the management of a big project keeps being easy as Project Center's file browser lets you always have a well sorted and categorized overview over all the files in your project.

Gorm

Gorm allows developers to quickly create graphical applications and to design every little aspect of the application's user interface.

Using drag and drop all types of objects like menus, buttons, tables, lists and browsers are easily added to the interface. With just the mouse you can resize, move or convert the objects or connect them to functions as well as edit nearly every aspect of them using Gorm's powerful inspectors.

With its intuitive interface Gorm makes creating, editing and testing complex user interfaces a piece of cake.

Developer's and Projects

Adam Fedor, fedor@gnu.org
GNUstep chief maintainer. Works on configuration, makefiles, and the backend libraries. Updates to the website.

Richard Frith-MacDonald, richard@brainstorm.co.uk, rfm@gnu.org
Main developer for base library. Developer for gui, and backend libraries. Wrote Gorm (InterfaceBuilder clone). Wrote GNUstep-guile interface and testsuite. Anyone wishing to submit test cases, please talk to me!

Nicola Pero n.pero@mi.flashnet.it, nicola@brainstorm.co.uk
Main developer for GNUstep-make; maintainer of the gui library. Wrote JIGS (the GNUstep Java/Objective-C bridge). Contributed to the GNUstep backend libraries, Objective-C runtime library, testsuite, and something to most other GNUstep core packages. Wrote tutorial documentation.

Fred Kiefer FredKiefer@gmx.de
Working on GUI and Windows backend and other backend. Lots of work on text and fonts.

Gregory Casamento greg_casamento@yahoo.com
Current main developer for Gorm. Lots of work done.

Pierre-Yves Rivaille pyrivail@ens-lyon.fr
Major developer for Gorm.

Alexander Malmberg alexander@malmberg.org
Wrote art backend. Lots of other contributions.

Developer on GUI library. Work on browsers, cells, windows, etc.

Philippe C.D. Robert, probert@siggraph.org

Donations

While GNUstep is a fairly large project, with 10-20 active developers and perhaps hundreds or more individuals and corporations that use GNUstep, it is not large enough to attract all the help we need. Yet our needs are growing each day. Our proposed solution is to begin accepting donations so that we can pay for some of the things that we can't get people to give us. Current ideas include a new icon set, a server-farm for testing and packaging, and better documentation.

Donate Two Ways!

  • Donate via the FSF
  • Donate via SPI, Inc. GNUstep is now associated with SPI and can accept donations through them!

Current Campaigns

We are already working on a compaign to fund a set of new icons. If you are interested in donating to this fund, please see the New Icons Fund page.

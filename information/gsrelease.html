August 7, 2000: GNUstep Version 0.6.6 Released

GNUstep continues improving and evolving with the new 0.6.6 release. One such important improvement is the long-awaited rewrite of the Distributed Object system that includes thread-saftey as well as compatibility with OpenStep and MacOS X (Note: This is interface compatiblity; GNUstep and MacOSX machines cannot talk to each other).

There where also great improvements in the gui library, including lots of improvment in the Text-handling classes, better interaction with window managers and improved font support.

February 17, 2000: GNUstep Version 0.6.5 Released

GNUstep has taken a major step forward with its latest release. While still lacking in several areas, a great deal of the interface has become much more robust and functional. Developers have already written over 20 basic applications from vector-drawing programs to file utilities and games. As with its godfather, the OpenStep system developed by NeXT, developers have noted that GNUstep allows faster development time and more flexibility than with other common application development libraries.

Perhaps the best example of how far GNUstep has come is the alpha release of the interface builder, Gorm, written entirely using the GNUstep libraries. Gorm allows a developer to graphically create user interfaces by dragging and dropping GUI elements such as buttons and sliders on to an application window. These elements can then be connected to a target object and told to perform a specific action (e.g. send a message to the target), all without writing a single line of code. A project management application, called Project Center should be released within a month or so.

This entire suite of applications, tools, and libraries, collectively called GNUstep should allow developers to rapidly develop cross-platform applications using a set of object-oriented tools and a well developed API. Additional tools allow developers to port applications from the well-known MacOS X development system to GNUstep with almost no changes in code.

GNUstep is a free, object-oriented development environment, consisting of libraries which implement the basic functionality of most common applications, as well as various tools to support the developement and execution of applications. GNUstep is maintained by a group of volunteers. If you would like to help out or ask questions, please see our web page at http://www.gnustep.org

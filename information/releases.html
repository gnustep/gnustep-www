New Software Releases

A list of the latest releases of GNUstep and related software. For more software, look at the Download page and User Apps.

GNUMail.app 0.6.0 (Aug 27, 2001)

GNUMail.app is a GNUstep mail program. Many improvements. Available here: http://www.collaboration-world.com/gnumail/

GNUMail.app 0.5.0 (Jul 25, 2001)

GNUMail.app is a GNUstep mail program. It's making rapid progress... Available here: http://www.collaboration-world.com/gnumail/

TCWebMail for Linux (Jul 19, 2001)

TCWebMail, a full featured web mail program which is the first commercial app based on GNUStepWeb, is now available for Linux. You can download RPMs from http://www.turbocat.de/. It is tested on Suse 7.1. Read the announcement (Currently only on German):

ggelite (Jul 4, 2001)

gelite is a space trading simulation (close to the old famous game elite (c) ) It uses openGL for it's rendering, the libSDL for the low-level things. This doesn't mean that this version is playable... you can get it here.

MusicKit (Jun 1, 2001)

There's talk that NeXT's MusicKit and SndKit are compiling on GNU/Linux using GNUstep. Check out they're web site www.musickit.org for more info.

StepTalk 0.1.0 (May 11, 2001)

StepTalk is Smalltalk interpreter for GNUstep. It is meant mainly for scripting GNUstep apps or for talking to registered named DO objects or apps. It is available at http://decef.elf.stuba.sk/~urbane/StepTalk This release is mainly for developers.

GNUMail.app 0.1.0 (May 10, 2001)

GNUMail.app is a GNUstep mail program. This is a developer release and may not work very well. Available here: http://www.collaboration-world.com/gnumail/

GSDict (May 03, 2001)

GSDict.app is a simple gui frontend to the dict utility. Available here: http://mapage.noos.fr/frederic.chauvin/ Please notice that since it is a wrapper, you will need to install dict which is available here: ftp://ftp.dict.org/pub/dict/dictd-1.5.5.tar.gz

MySQL EOFAdaptor (Feb 07, 2001)

A new and totally revised version of the MySQL EOFAdaptor is available at http://www.prnet.de/RegEx/ It features better reverse modelling and speed, fetch limits (ugly!) and debugging.

Gomoku 1.1.0 (Jan 14, 2001)

Gomoku.app 1.1.0 is out. The main improvement is that the board has been completely redesigned - I made a completely new set of images and now the board looks like (attempts at looking like) a Go board. It's pretty cool compared to what it looked like before. http://www.gnustep.it/nicola/Applications/Gomoku

GSBench 0.5.0 (Jan 14, 2001)

A new release of GSBench is available. It puts the tests in bundles to make it easy to add new ones. Get it from the http://www.nice.ch/~phip/softcorner.html or ftp.gnustep.org

GWorkspace 0.1.4 (Dec 20, 2000)

A new release of GSWorkspace was released by Enrico Sersale. Some new features and lots of bug fixes. Get it from the http://www.gnustep.it/enrico/gworkspace/.

JIGS Version 1.0.0 (Dec 03, 2000)

A great implementation of a Java bridge to Objective-C. You can use GNUstep libraries from Java and Java from Objective-C. More info and download at http://gnustep.it/jigs/.

Full GNUstep GNU/Linux distribution [LastStep] (Nov 09, 2000)

Dennis Leeuw has put together a full GNU/Linux distribution featuring GNUstep called LastStep. See the home page at http://gnustep.stone-it.com/. Note that this is preliminary release and you should be very careful about installing it on your system.

SndKit ported, others (Nov 06, 2000)

Some people are working on porting SndKit and MusicKit to MacOSX and GNUstep. More info may be available soon. For now the latest release is at ftp://ftp.tomandandy.com

GNU 3DKit version 0.2.0 (Nov 01, 2000)

I am happy to announce the availability of the GNU 3DKit 0.2.0. The GNU 3DKit is a LGPLed scenegraph API based on OpenGL, GNUstep and Objective-C. http://feivel.unibe.ch/GNU3DKit/. More info at http://www.fsf.org/software/gnu3dkit/gnu3dkit.html

ProjectCenter 0.1.0 (Sep 20, 2000)

Progress continues on ProjectCenter with some additions and bug fixes. At this point it is even usable, if primitive (and probably buggy). ProjectCenter Page

GSWorkspace 0.1.2 (Sep 14, 2000)

A new release of GSWorkspace (formerly called Xws) was released by Enrico Sersale. A lot of old code has been rewritten and improved. Get it from the http://www.gnustep.it/enrico/gworkspace/.

GSBench 0.4.1(Sep 13, 2000)

A minor update to the GSBench program has been released. Get it from the GNUstep ftp site or from here.

Gomoku (Sep 7, 2000)

Nicola released his version of the Gomoku game that runs on GNUstep. Get it from http://www.gnustep.it/nicola/Applications/Gomoku/

nib2gmodel 0.6.6 (Sep 1, 2000)

The latest verision of nib2gmodel fixes a few translation problems but it is still likely that you will have to edit things by hand. Read the README file for more info. dowload page.

Project Center pre-pre-pre-release (Aug 28, 2000)

A very early snapshot of the ProjectCenter has been released. If your willing to look at it and work on it, please download it from there. Otherwise wait for a more stable version.

GNU 3DKit bug fixes, improved web site(Aug 20, 2000)

Philippe C.D. Robert writes: "I have fixed a very severe bug which caused a segfault when compiling the RenderKit not as debug target. The second impact is the class prefix, which is now G3D for all classes. I decided to do this, since the kit is now officially dubbed the GNU 3DKit." The new web location is http://feivel.unibe.ch/GNU3DKit.

GNUstep core libraries release 0.6.6 (Aug 7, 2000)

A new version of the GNUstep core libraries and tools was released. It contains a wealth of new and improved features including re-written Distributed Objects and NSText classes. ftp://ftp.gnustep.org/pub/gnustep/core. See the Press Release for more info.

First (alpha) version of the JIGS (Jul 31, 2000)

A first version of JIGS, the "JAVA Interface for GNUstep" is available. It works well but doesn't have tools for automatic generation of wrappers yet. Get it from http://www.gnustep.it/jigs/

First (alpha) version of the GNU 3DKit (Jul 22, 2000)

A first version of the 3DKit can now be downloaded from http://feivel.unibe.ch/~robert/. It's still very much in development so expect a lot of work to get it going. There are also screenshots...

Display Ghostscipt Version 0.5.10 (Jun 18, 2000)

A new version of DGS has been released. It includes mostly bug fixes from the previous version. Available at the GNUstep ftp site in the dgs directory.

Mini-Tutorials (Jun 16, 2000)

Two new mini-tutorials written by Nicola Pero are on the GNUstep Documentation Page. Check them out and/or volunteer to write your own.

Loginpanel App (Jun 9, 2000)

A GNUstep login panel similar to NeXTsteps login panel. The images are now being loaded correctly and the panel centers itself on the screen properly. There are still a few more bugs to be hashed out. Available at the GNUstep ftp site in the user-apps directory.

New GeometryKit Snapshot (Jun 1, 2000)

Objective-C classes for 3D drawing. This is a new developer snapshot featuring improvements and initial support for MacOSX and YB/Windows. Available at http://feivel.unibe.ch/~robert/

KDevelop Objective-C Patches (May 27, 2000)

Here are patches to provide Objective-C support for the KDevelop IDE, the KWrite text editor and the KDoc javadoc-like documentation extraction tool as well as other tools. It is now available at the gnustep ftp site (under kdkobjc) and other mirror sites in the contrib directory.

Openstep2GNUConverter (Apr 28, 2000)

Openstep2GNUConverter is a program for converting Openstep makefiles to GNUstep makefiles. It is now available at the gnustep ftp site and other mirror sites in the contrib directory. Updated May 8, 2000 to handle Makefiles for OpenStep and GNUstep in the same directory

GNUstep Guile Adapter and Testsuite (Mar 28, 2000)

The GNUstep guile adapter allows you to access the GNUstep classes via the guile scripting language. This adaptor also allows the developers to maintain a testsuite that can be used for testing the functionality of the GNUstep libraries. See the Download for more info.

GNUstep Core Libraries Version 0.6.5 (Feb 17, 2000)

GNUstep has taken a major step forward with its latest release. While still lacking in several areas, a great deal of the interface has become much more robust and functional. Developers have already written over 20 basic applications from vector-drawing programs to file utilities and games... See the Press Release for more info.

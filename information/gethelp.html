Mailing Lists and Newsgroups

To (un)subscribe to one of these lists, send a message to "list"-request@gnu.org with (un)subscribe in the subject line (be sure to add the "-request" at the end of the list name. You can also subscribe using a web interface. Go to the main listinfo page and select the desired mailing list from there. To change your subscription (unsubscribe, change options), go to the options page for the list you are interested in. For example, discuss-gnustep is at: http://mail.gnu.org/mailman/options/discuss-gnustep/your_email_addess

  • discuss-gnustep@gnu.org
    For all discussions and questions. We also would like to hear about ideas for the applications for the GNUstep environment and related issues (e.g Interface Modeller).
    To un/subscribe send mail to: discuss-gnustep-request@gnu.org with the subject line containing "un/subscribe" or try the web interface. This list is mirrored on the usenet group gnu.gnustep.discuss.

  • info-gnustep@gnu.org
    For info and announcements related to GNUstep libraries and applications. To un/subscribe send mail to: info-gnustep-request@gnu.org with the subject line containing "un/subscribe" or try the web interface. This list is mirrored on the usenet group gnu.gnustep.announce.

  • help-gnustep@gnu.org
    For help with GNUstep libraries and applications. This list is rarely read, so it is better to use discuss-gnustep. To un/subscribe send mail to: help-gnustep-request@gnu.org with the subject line containing "un/subscribe" or try the web interface. This list is mirrored on the usenet group gnu.gnustep.help.

  • bug-gnustep@gnu.org
    A mailing list for submitting bug reports and patches. To un/subscribe send mail to: bug-gnustep-request@gnu.org with the subject line containing "un/subscribe" or try the web interface. This list is mirrored on the usenet group gnu.gnustep.bug.

  • apps-gnustep@gnu.org
    For discussion related specifically to GNUstep applications. To un/subscribe send mail to: apps-gnustep-request@gnu.org with the subject line containing "un/subscribe" or try the web interface.

  • GNUstep developers list
    This mailing list has been established to keep the noise low when it comes to core topics and generally boring discussion about technical aspects of GNUstep. To subscribe try the web interface. P.S. Most of the interesting stuff goes on discuss-gnustep anyway.

  • DGS developers list
    This mailing list has been established to keep the noise low when it comes to DGS topics. To subscribe you have to contact The GNUstep Maintainers directly.

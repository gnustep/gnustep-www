Bug Reporting

Please report your issues (bugs, or other requests) on the tracking system of the respective project.

The tracking system on Savannah is for legacy purposes only. Please do not report new issues there.

Core Project

Each project has its separate issue tracker on the GNUstep GitHub project page. For your convenience, here some quick links to the most used projects:

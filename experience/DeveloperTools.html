GNUstep Developer Tools

Development Tools

Using Project Center and Gorm, developers can quickly design and build cross-platform applications in Objective-C or Java. Either language can be used as an interface to the GNUstep frameworks. Objective-C elegantly adds a runtime and small amount of syntax to ANSI C to provide a true object-oriented environment. Objective-C support is built into the standard distribution of gcc.



Apart from its great API and libraries GNUstep features some world class developer tools. As these tools aid you in the daily aspects of programming and project management you will notice how much quicker and easier developing is with GNUstep.
With these tools GNUstep extends its sense of rapid application developement even one more step...

GUI Tools

GNUstep features two great graphical applications that help you to manage and create new projects, design and edit graphical user interfaces, compile and debug your programs.

Project Center

Project Center is GNUstep's graphical integrated developement environment (IDE). It helps you to create all different kinds of projects like Applications, Tools, Libraries and Bundles.

Project Center allows you to easily add and remove, edit and search files; writes the project makefiles accordingly and supports you in the actual process of building and debugging your project.

Even the management of a big project keeps being easy as Project Center's file browser lets you always have a well sorted and categorized overview over all the files in your project.

Get to know more about Project Center
or read how to download this great app!

Gorm

Gorm allows developers to quickly create graphical applications and to design every little aspect of the application's user interface.

Using drag and drop all types of objects like menus, buttons, tables, lists and browsers are easily added to the interface. With just the mouse you can resize, move or convert the objects or connect them to functions as well as edit nearly every aspect of them using Gorm's powerful inspectors.

With its intuitive interface Gorm makes creating, editing and testing complex user interfaces a piece of cake.

Language Interfaces

Developing with GNUstep is not strictly tied to Objective-C. Using several language interfaces you can use your favorite programming language to get access to the advantages of the GNUstep libraries.

JIGS

JIGS stands for "Java Interface for GNUstep". It is a package allowing integration between Java and Objective-C. The main purpose of JIGS is to allow Java programmers to use the GNUstep libraries from Java.

The JIGS Homepage has got all the information you may want.

RIGS

RIGS stands for "Ruby Interface to GNUstep" and is a library that allows programmers to develop GNUstep applications using the remarkable Ruby language, which is both easy to learn and flexible to fit your needs.

Now jump in, check out a little example program and Download RIGS

Scripting in GNUstep

There are currently two packages which enhance GNUstep to be scriptable making it even more dynamic and superior.

StepTalk

With StepTalk you can create scriptable servers or applications using GNUstep. It is language independent: you can use any available scripting language that is provided as a separate bundle.

The StepTalk page at GNUstep.org should be consulted for more information.

GNUstep-Guile

Also GNUstep features a extension to make use of the GUILE scripting language. Using this library you can easily add scripting capabilities to your GNUstep applications.

GNUstep-Guile can be downloaded from the GNUstep FTP-Server.
